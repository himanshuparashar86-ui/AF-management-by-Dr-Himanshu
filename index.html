Patient transfer and data backup

Import received file

Download the TXT attachment from WhatsApp, then select it here. The app-generated TXT file contains a readable summary and a protected structured section so the full patient record and approved orders can be restored. Older JSON handover files are also accepted.

Doctor — complete patient data backup

Export all records currently stored on this device. PDF opens the print window; choose “Save as PDF”. JSON is the restorable full backup.

Restore complete JSON backup

Keep a copy of the JSON backup outside this device. PDF and text files are readable exports, not restorable app backups.

Staff — My Complete Backup

Creates a restorable TXT backup containing this staff profile, only this staff member’s patient records, saved checklists, local treatment drafts and relevant history.

Restore my staff backup

Keep this file outside the PWA (for example, in a secure device backup location). A staff backup can also restore the staff profile on a newly installed copy of this PWA.

Exported JSON and TXT backups contain identifiable patient information and are not encrypted in this prototype. Share only through organisation-approved channels and store securely.
